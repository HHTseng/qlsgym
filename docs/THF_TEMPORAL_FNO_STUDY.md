# ThF+ temporal FNO study

## Question and domain

This study changes the dynamics surrogate.  It does not add RL-step history to
PPO or SAC.

There are two time variables:

$$
\tau\in[0,\tau_{\max}]
\quad\text{(coherent time within one pulse)},
\qquad
t\in\{0,\ldots,H\}
\quad\text{(measurement and control step)}.
$$

Attention acts only along the 200-point physical grid in `tau`.  For a
Hamiltonian block `f` with `M_f` molecular states and outcome `k` in `{0,1}`, the
surrogate learns the operator

$$
\mathcal T_f:(\omega,\sigma)
\longmapsto
\left(B^{(f)}_{(\omega,\tau_r,\sigma),k}\right)_{r,k},
\qquad
B^{(f)}_{\alpha,k}\in\mathbb R_{\ge0}^{M_f\times M_f}.
$$

For a normalized block population `s`, the unnormalized branch population,
Born mass, and posterior are

$$
v_{\alpha,k}=B_{\alpha,k}s,
\qquad
p_k(s,\alpha)=\mathbf1^{\mathsf T}v_{\alpha,k},
\qquad
F_{\alpha,k}(s)=\frac{v_{\alpha,k}}{p_k(s,\alpha)}.
$$

This factorization preserves exact linearity in `s`.  A history-conditioned
model across `t` would be identifiable only after adding latent drift or other
nonstationary physics, so it is outside the present stationary experiment.

## Implemented operator

The control embedding `C(omega,sigma)` first passes through a one-dimensional
FNO.  Its latent trajectory is transposed into physical-time tokens, augmented
with a continuous Fourier embedding of `tau/tau_max`, and processed by a small
bidirectional Transformer encoder:

$$
H_F=\mathrm{FNO}_{\phi}(C),
\qquad
Z_0=H_F^{\mathsf T}+E_{\tau},
$$

$$
Z=Z_0+g\left(\mathrm{Transformer}_{\psi}(Z_0)-Z_0\right),
\qquad
g=\mathrm{sigmoid}(g_{\rm raw}),
$$

$$
\widehat B_{\alpha}=
\mathrm{softmax}_{\text{output state}}(WZ+b).
$$

The initial gate is `g=0.075`.  The implementation enforces

$$
\widehat B_{(\omega,0,\sigma)}=
\begin{bmatrix}I_{M_f}\\0\end{bmatrix},
\qquad
\mathbf1^{\mathsf T}\widehat B_{\alpha}=\mathbf1^{\mathsf T},
\qquad
\widehat B_{\alpha}\ge0,
$$

and uses the exact static map beyond three resonance half-linewidths.  It does
not impose a population semigroup law because discarding quantum coherence
makes such a law invalid for `B`.

Implementation:

- `src/qlsgym/surrogate/temporal_fno.py`: continuous-time embedding, gated
  attention, stochastic columns, and the pure-Transformer ablation.
- `src/qlsgym/surrogate/column_train.py`: exact-column cache, branch-aware loss,
  derivative matching, and Fourier trajectory loss.
- `scripts/audit_thf_fno_manifest.py`: structural, branch, and
  resonance-stratified temporal metrics.
- `tests/test_temporal_column_fno.py`: shape, positivity, normalization,
  zero-time identity, input linearity, determinism, gradients, and checkpoint
  round trips.

All labels are exact effective-Hamiltonian transfer columns.  No target is
generated by the downloaded FNO.

## Experimental design

The hard pilot set is

$$
\mathcal P_{\rm pilot}
=\{(0,+),(0,-),(1,+),(1,-),(9,+),(11,+)\}.
$$

The last pair is mandatory because it was the worst `column_v2` case.  Every
new model uses the same frequency samples, exact targets, optimizer, seed, and
branch-aware objective.  The initial architecture isolation compares:

| model | role |
|---|---|
| downloaded `mix` | historical state-map baseline |
| `column_v2` | prior structured baseline |
| retrained column FNO | same-budget spectral baseline |
| FNO + one attention layer | minimal temporal model |
| FNO + two attention layers | planned candidate |

The controlled refinement adds derivative loss, derivative plus spectral loss,
a shuffled-time negative control, and a pure-Transformer ablation.

The primary acceptance thresholds are applied separately to every pair:

| metric | threshold |
|---|---:|
| zero-time identity TV, maximum | 0.001 |
| input-linearity TV, P95 | 0.001 |
| off-resonance joint TV, P95 | 0.005 |
| branch-mass absolute error, P95 | 0.005 |
| conditional TV for branch mass at least 0.01, P95 | 0.05 |
| conditional TV for branch mass at least 0.001, P95 | 0.10 |
| block-local termination error | 0.005 |

The pilot promotes a model only if all six pairs pass all seven thresholds.  A
full model must pass all 24 block/polarization pairs.  Only then may optimized
PPO and refined SAC be trained under it.  Their exact closed-loop acceptance
conditions are an absolute failure-rate gap of at most 0.02 and an absolute
average-action gap of at most one action.

## Reproduction

On Tara, with the `qlsgym` conda environment active and the downloaded `mix`
manifest retained at `$QLSGYM_WORK/checkpoints/thf/mix.json`:

```bash
cd ~/qlsgym_seqFNO_RL
GPU0=0 GPU1=2 bash scripts/run_thf_temporal_fno_pilot.sh
GPU0=0 GPU1=2 bash scripts/run_thf_temporal_fno_refinement.sh
```

Both launchers use only GPUs 0 and 2 and run at most one process on each GPU.
The full launcher `scripts/run_thf_temporal_fno_full.sh` requires an explicitly
promoted attention depth.

## Result: 1 October 2026

The study trained 48 models and consumed an estimated 1.97 GPU-hours on Tara.
All repository tests passed: 177 passed, 17 skipped, and three slow tests were
deselected.  The initial 512-frequency, 80-epoch screen was followed by four
controlled ablations and a matched-budget 768-frequency, 100-epoch check.

| model | pilot pairs passing all gates | worst branch-mass P95 | worst conditional TV P95, branch mass at least 0.01 | on-resonance derivative error | on-resonance spectral error |
|---|---:|---:|---:|---:|---:|
| downloaded `mix` | 0/6 | 0.01659 | 0.12558 | 0.002067 | 0.000199 |
| `column_v2` | 2/6 | 0.07254 | 0.27775 | 0.002340 | 0.000259 |
| temporal FNO, matched budget | **4/6** | 0.07532 | 0.32937 | 0.002342 | **0.000172** |

The temporal FNO improves all four block-0 and block-1 pairs enough to pass the
complete gate set.  The pairwise comparison is:

| pair | `column_v2` passes | temporal passes | branch-mass P95: column / temporal | conditional TV P95: column / temporal | termination error: column / temporal |
|---|:---:|:---:|---:|---:|---:|
| `(0,+)` | no | yes | 0.00533 / **0.00453** | 0.04712 / **0.04467** | **0.00433** / 0.00441 |
| `(0,-)` | no | yes | 0.00538 / **0.00453** | 0.04332 / **0.03907** | 0.00504 / **0.00482** |
| `(1,+)` | yes | yes | 0.00470 / **0.00369** | 0.04098 / **0.03703** | 0.00387 / **0.00385** |
| `(1,-)` | yes | yes | 0.00464 / **0.00378** | 0.03771 / **0.03247** | **0.00474** / 0.00481 |
| `(9,+)` | no | no | **0.00220** / 0.00223 | **0.00662** / 0.00742 | **0.01265** / 0.01478 |
| `(11,+)` | no | no | **0.07254** / 0.07532 | **0.27775** / 0.32937 | 0.10705 / **0.10697** |

Thus attention helps the easy and moderate blocks but does not repair the two
failure modes that matter for closed-loop control: block 9 termination decisions
and block 11/+ branch inference.  The learned attention gate remains small—the
matched-budget median is 0.0775 from an initialization of 0.075—so the trained
network uses attention as a correction rather than replacing the spectral
trajectory.

Derivative loss lowers derivative error but leaves the branch and termination
gates unchanged.  The spectral term is also neutral.  The pure Transformer has
substantially worse validation and temporal errors.  A shuffled-time negative
control improves some fixed-grid branch metrics while worsening temporal
derivative and spectral errors; therefore that improvement is evidence of
grid-position memorization, not physical temporal ordering.

The six-pair promotion rule failed.  Full 24-pair training and new RL training
were therefore stopped.  This is a scientific gate, not a compute failure.  The
valid RL references remain the downloaded-`mix` results from `FNO_RL_optuna`:

| controller | exact failure | exact average actions |
|---|---:|---:|
| optimized PPO | 41.78% | 51.37 |
| refined SAC | 57.07% | 59.85 |
| physics elimination | **29.36%** | 51.49 |

No temporal-FNO RL score is reported because training a controller on a
surrogate that failed the declared branch-aware gates would not be an interpretable
comparison.  The next useful model change should target block-conditioned
branch mass and posterior accuracy directly, rather than add more attention
layers.
